# 檢查編譯器錯誤

<a id="trigger"></a>

## 觸發條件

編譯或型別檢查失敗，阻擋了本機驗證或 CI。

<a id="workflow"></a>

## 工作流程

1. 執行儲存庫的編譯與型別檢查指令。
2. 依檔案與型別彙整錯誤摘要。
3. 優先修復信心度最高的問題。
4. 重新執行檢查，直到透過或受阻為止。

<a id="output"></a>

## 輸出

- 目前的編譯與型別檢查狀態
- 依檔案與類別分組的錯誤摘要
- 已套用的修復與剩餘的阻擋專案
