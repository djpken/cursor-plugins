# 新分支與 PR

<a id="trigger"></a>

## 觸發條件

開始需要透過乾淨分支與拉取請求流程交付的工作。

<a id="workflow"></a>

## 工作流程

1. 確保工作樹是乾淨的，或已明確處理。
2. 從最新的 main 建立描述性分支。
3. 完成實作與測試。
4. 提交聚焦的變更並推送。
5. 建立簡潔的 PR，包含摘要與測試說明。

<a id="guardrails"></a>

## 防護措施

- 保持分支範圍聚焦於單一變更集。
- 在請求審查前包含驗證說明。

<a id="output"></a>

## 輸出

- 新分支名稱
- PR 摘要與測試說明
- PR URL
