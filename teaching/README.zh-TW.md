# 教學外掛

教學工作流程：技能對映、練習計畫與回饋迴圈。

<a id="installation"></a>

## 安裝

```bash
/add-plugin teaching
```

<a id="components"></a>

## 組成元件

<a id="skills"></a>

### 技能

| 技能 | 描述 |
|:------|:------------|
| `create-learning-path` | 建立個人化學習路線圖，包含里程碑與練習檢查點 |
| `run-learning-retrospective` | 評估進度、找出阻礙並調整學習計畫 |
