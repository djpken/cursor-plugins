<a id="run-a-learning-retrospective"></a>

# 執行學習回顧

<a id="trigger"></a>

## 觸發條件

學習者完成一個里程碑，需要根據資料驅動的調整來更新他們的計畫。

<a id="workflow"></a>

## 工作流程

1. 檢視已完成的工作與目標成果的差距。
2. 找出常見的阻礙與薄弱概念。
3. 優先排序哪些需要強化，哪些可以暫緩。
4. 調整進度與即將的練習任務。
5. 設定下一個里程碑與可量測的檢查點。

<a id="tools"></a>

## 工具

- 使用 Ask user 工具。

<a id="output"></a>

## 輸出

- 進度回顧
- 更新的學習計畫
- 下一個里程碑定義
