<a id="create-a-learning-path"></a>

# 建立學習路徑

<a id="trigger"></a>

## 觸發

在多次會話中逐步建立某個主題的能力。

<a id="workflow"></a>

## 工作流程

1. 評估基礎知識與目標成果。
2. 將主題從基礎排序到應用練習。
3. 定義里程碑專案與時間限制的檢查點。
4. 加入刻意練習的練習題，並附上回饋標準。
5. 檢視進度並調整節奏。

<a id="tools"></a>

## 工具

- 使用 Ask user 工具。

<a id="guardrails"></a>

## 防護措施

- 確保里程碑在既定時間內可達成。
- 每個階段都包含練習與反思。
- 避免資源過載，優先選用少量教材。

<a id="output"></a>

## 輸出

- 週週或里程碑式計畫
- 練習作業
- 進度檢視評量表
