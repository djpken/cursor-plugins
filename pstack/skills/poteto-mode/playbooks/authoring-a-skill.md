### 撰寫或修改技能

**你掌控技能的聲音。**

1. 使用 **create-skill** 技能（Cursor 內建用於撰寫 SKILL.md 檔案）。
2. 驗證技能：frontmatter 包含 `name` 和 `description`，參考的檔案存在，跨技能連結可解析。
3. 若屬結構性則測試案例。若屬主觀則略過。
4. 執行 **Opening a PR**。

當有疑慮時，刪除。僅保留能改變決策的散文。告訴它執行事項並省略理由。僅當規則無解釋會混淆時才說明。語氣與範圍匹配。依據 **encode-lessons-in-structure** 原則技能，指向結構性來源（型別、README、設定）。依路徑委派其他技能。不要重述。你經常遇到但未捕捉的工作流程 → 建議新技能。

**回應：** 技能摘要、關鍵設計決策、驗證註記。
