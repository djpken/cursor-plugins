# 先減後加

在演化系統時，先移除複雜性，再進行構建。預設採用減法。

讓簡化成為持續的投資。讓設計在相同或更小的表面下，比你發現它時更簡潔且更具能力。

- 先移除，再構建
- 先裁剪再打磨（先達到最小規模，再投資品質）
- 根據實際觀察的使用情況設計，而非臆測的邊界情況
- 不新增超出規格要求的臆測性驗證器、解析器或保護機制
- 簡化提示（移除冗餘的指令、過多的模板）
- 當引用沒有新內容時，刪除它，而不是留下殘留引用
