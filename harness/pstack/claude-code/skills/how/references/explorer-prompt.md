<a id="output"></a>

## 輸出

<a id="components-found"></a>

### 發現的元件
關鍵的型別、服務、類別和抽象。對於每一項：名稱、檔案路徑，以及一句話描述其功能。

<a id="flow"></a>

### 流程
逐步執行流程。對於每一步：執行哪個函式/方法、位於哪個檔案、執行什麼操作、接下來呼叫什麼。包含在各步驟之間流動的資料。

<a id="files-read"></a>

### 已讀取的檔案
你在探索期間讀取的每個檔案，以便說明者可以參考它們。

<a id="boundaries"></a>

### 邊界
此子系統與程式碼庫其他部分連線的地方。輸入和輸出。

<a id="non-obvious-things"></a>

### 非直覺之處
任何令人驚訝、出於歷史原因或容易出錯的內容。那些看起來應該以某種方式運作但實際以另一種方式運作的部分。

<a id="open-questions"></a>

### 未解問題
任何你無法完全追蹤或理解的部分。誠實地說明缺口。
